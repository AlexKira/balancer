# BridgeNetUse Traffic Management Utility

Linux network traffic management toolkit for firewall, NAT, forwarding control, and operational automation.

The project provides command-line utilities and automation scripts for managing Linux network infrastructure, including system networking configuration, firewall/NAT policies, traffic logging, and operational maintenance tasks.

## Features

- Apply and restore Linux network sysctl configuration
- Initialize and manage conntrack settings
- Firewall rule management using iptables
- NAT rule management
- Network forwarding configuration automation
- INPUT and FORWARD traffic logging
- Log maintenance operations
- System service and timer inspection
- Integration with Python-based network configuration extensions

## Requirements

- Linux
- Bash
- Python 3
- iptables
- systemd

## Operations

The utility provides commands for:

- applying and restoring network system configuration;
- applying firewall and NAT rules;
- resetting network policies;
- inspecting firewall and NAT configuration;
- reviewing traffic logs.
